# Getting started with flappin-ufo

A Flappy Bird-style web game where you pilot a UFO through fields of asteroids, with a global leaderboard and ghost replay.

## Install

```bash
git clone https://github.com/nirholas/flappin-ufo.git
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/flappin-ufo.git
cd flappin-ufo
```

Available commands:

| Command | Runs |
|---|---|
| `npm run dev` | `vite` |
| `npm run build` | `tsc -b && vite build` |
| `npm run lint` | `eslint . --report-unused-disable-directives --max-warnings 0` |
| `npm run test` | `vitest run` |
